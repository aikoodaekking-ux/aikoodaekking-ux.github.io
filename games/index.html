리플렉스 클리커

60초 동안 화면에 나타나는 원을 터치해서 점수를 쌓아보세요. 노란 원은 기본 점수, 초록 보너스 원은 고득점, 빨간 트랩 원은 피해야 합니다. 콤보를 유지할수록 점수 배율이 올라갑니다.

플레이 방법

  1. 시작하기 버튼을 누르면 60초 라운드가 시작됩니다.
  2. 화면에 나타나는 원을 빠르게 터치/클릭하세요.
  3. 초록색 보너스 원은 더 높은 점수를 주지만 금방 사라집니다.
  4. 빨간색 트랩 원을 클릭하면 점수가 깎이고 콤보가 끊깁니다.
  5. 라운드가 끝나면 점수가 기록되고, 최고 점수는 브라우저에 자동 저장됩니다.
  6. "다시 하기"를 눌러 바로 새 라운드를 시작할 수 있습니다.
